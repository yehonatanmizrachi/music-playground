# Audio credits

The loops in this folder are short arrangements written for this project and rendered by
`tools/render-loops.py` from single recorded notes. The note samples come from:

| Instruments used | Original source | License |
| --- | --- | --- |
| piano, violin, contrabass, flute, harp, trumpet, organ | [Versilian Studios VSCO 2 Community Edition](https://vis.versilstudios.net/vsco-community.html) | CC0 (public domain) |
| acoustic guitar | [University of Iowa Electronic Music Studios](https://theremin.music.uiowa.edu/MIS.html) | free to use without restriction |
| electric bass, saxophone | [Karoryfer Samples](https://www.karoryfer.com/karoryfer-samples) | free samples |
| drum kit (kick, snare, hi-hat, toms) | [web-audio-samples](https://github.com/cwilso/web-audio-samples) by Chris Wilson, via [Tone.js audio](https://github.com/Tonejs/audio) | Apache 2.0 |

The edited, pitch-matched note files were taken from
[nbrosowsky/tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) (MIT), which collects them.
